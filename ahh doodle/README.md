Hi! to you who may see this, this is my first attempt to make a neural network from scratch, and connect it to a draw panel to identify written digits.
----------------------------
Libraries required for functions:
numpy
pickle(probably preinstalled)

Libraries required for drw2:
customtkinter
PIL
scipy
(Libraries required for functions)

Libraries required for data:
idx2numpy
(Libraries required for functions)
----------------------------
There is a trained model in the folder, but you can also train one on your own, perhaps tweaking the values or learning rate, and see if you can train a better one!(My model got 97.9% correct)
This model is based on multilayer perceptron, which is suitable for beginners who tries making a network, like me.
The .venv folder is optional as you have the modules installed.
